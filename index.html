Pemrograman Web

Materi Pembahasan

1. Pengenalan Elemen Dasar HTML

HTML (HyperText Markup Language) adalah bahasa standar untuk membuat dan menyusun struktur halaman web. Elemen dasar HTML terdiri dari tag pembuka, konten, dan tag penutup.

  • <!DOCTYPE html> - Deklarasi tipe dokumen HTML5
  • <html> - Elemen utama penutup seluruh dokumen
  • <head> - Berisi metadata, judul, dan link stylesheet
  • <body> - Berisi seluruh konten visual web
2. Struktur Atribut dan Tag

Tag digunakan untuk menandai awal dan akhir elemen, sedangkan atribut memberikan informasi atau konfigurasi tambahan pada elemen tersebut.

Tag Atribut Utama Fungsi
<a> href, target Membuat tautan/hyperlink halaman
<img> src, alt, width Menampilkan gambar pada halaman
<input> type, placeholder, name Membuat formulir masukan pengguna
3. Dasar Styling dengan CSS

CSS (Cascading Style Sheets) mengatur tampilan visual elemen HTML seperti warna, tata letak, font, dan jarak antar elemen.

    Metode Penerapan CSS:
  1. Inline CSS - Langsung pada tag HTML via atribut style
  2. Internal CSS - Dalam tag <style> di bagian head
  3. External CSS - Menggunakan file .css terpisah
4. Layouting dan Framework Bootstrap

Bootstrap menyediakan sistem Grid (12 kolom) dan komponen siap pakai untuk mempercepat pembuatan desain tata letak web yang responsif di berbagai perangkat.
